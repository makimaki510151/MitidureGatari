# 道連れ語り — 迷宮図

SW2.5キャンペーン『道連れ語り』用の、ブラウザ完結型ダンジョンマップです。インストール不要で、`index.html` を開けば使えます。

状況は **ブラウザごと** に `localStorage` へ自動保存されます（マップ、探索位置、マスク解除、扉の開閉）。

## モード

- **クリエイト** … 見下ろしグリッドに道・部屋・扉・階段を置いて迷宮を組み立てます。
- **プレイ** … 作ったマップをマス移動で探索します。未到達の区画はマスクされます。

## クリエイト

| 操作 | 内容 |
| --- | --- |
| 道 | ドラッグで通路を描く |
| 部屋 | ドラッグで矩形の部屋を置く |
| 扉 | 歩けるマス同士の境界をクリック。見た目・開く方向・蝶番を指定可能 |
| 階段 | 上り／下り／はしご／転移門。別階層または別の場所レイヤーへ接続 |
| 開始 | プレイ開始位置 |
| 消去 | マスを空にする |
| ＋階 / ＋場所 | レイヤー追加（階層と別地点を区別できます） |

ホイールで拡大、Space+ドラッグ（または中ボタン）で視点移動。Ctrl+Z で取り消し。

同じ部屋（または扉で区切られていない道）は **ひとつの区画** です。プレイ時、区画に入るとマスクがまとめて外れます。クリエイト中は「探索マスクをプレビュー」で確認できます。

## プレイ

- **WASD**（または矢印）で1マスずつ移動
- **F** で正面の扉を開閉
- 階段・転移門に乗ると接続先へ移動
- 未訪問区画は闇。進入した区画だけが一気に開示されます

「探索リセット」で位置・マスク・扉状態だけを開始時点に戻せます。マップは消えません。
