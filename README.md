# 道連れ語り — 迷宮図

SW2.5キャンペーン『道連れ語り』用の、ブラウザ完結型ダンジョンマップです。インストール不要で、`index.html` を開けば使えます。

状況は **ブラウザごと** に `localStorage` へ自動保存されます（マップ、探索位置、マスク解除、扉の開閉）。

## 起動

ESモジュールを使うため、ファイルを直接開くのではなく、ローカルサーバ経由で開いてください。

```bash
python3 -m http.server 8765
```

ブラウザで `http://localhost:8765/` を開きます。

起動すると、まず **プレイ** か **クリエイト** を選びます。

- **プレイ** … マップJSONファイルを読み込んで探索します。付属の `maps/sample.json` を使えます。
- **クリエイト** … 白紙のマップから組み立てます。

## モード

- **クリエイト** … 見下ろしグリッドに道・部屋・扉・階段・穴・橋を置いて迷宮を組み立てます。
- **プレイ** … 読み込んだマップ（または作ったマップ）をマス移動で探索します。未到達の区画はマスクされます。

## クリエイト

| 操作 | 内容 |
| --- | --- |
| 道 | ドラッグで通路を描く |
| 部屋 | ドラッグで矩形の部屋を置く |
| 扉 | 歩けるマス同士の境界をクリック。見た目・開く方向・蝶番・**番号**を指定可能。同じ番号の扉は階層・場所をまたいで開閉が連動（初期で開いている扉は閉じ、閉じている扉は開く）。**隠し扉（壁）** は壁に擬態。**振れ扉** は開くと開いた側の通路を塞ぎ、その辺でも同じ扉として開閉できる |
| 階段 | 上り／下り／はしご／転移門。別階層または別の場所レイヤーへ接続 |
| 文字 | マスに1文字を置く。部屋番号などの表示に使えます |
| 穴 | 道・部屋の上にマス単位で形と大きさを決めて置く。穴の上は歩けない。同じマスに複数のオブジェクトを重ねられる |
| 橋 | 穴の上に重ねて置く。橋があるマスは歩ける。視界の区画は部屋・道のまま（穴では割れない） |
| 開始 | プレイ開始位置 |
| 消去 | マスを空にする |
| ＋階 / ＋場所 | レイヤー追加（階層と別地点を区別できます） |
| JSON | マップを書き出し・読み込み・テキスト編集。適用するとクリエイト／プレイの両方で使えます |
| 画面を共有 | 今見ている画面を `PlayView/` URL で配信。開いた全員が同じ画面を視聴します |

ホイールで拡大、Space+ドラッグ（または中ボタン）で視点移動。Ctrl+Z で取り消し。

同じ部屋（または扉で区切られていない道）は **ひとつの区画** です。プレイ時、区画に入るとマスクがまとめて外れます。クリエイト中は「探索マスクをプレビュー」で確認できます。

隠し扉はクリエイトでは菱形マークで分かり、プレイでは普通の壁に見えます。

## プレイ

プレイ中はサイドバーを隠し、マップが画面全体に広がります。右上の「全画面」でブラウザ全画面にもできます。

- **WASD**（または矢印）で1マスずつ移動
- **F** で正面の扉を開閉（振れ扉は開いた側の通路からも同じ扉を操作できます）。同じ番号の扉は、別階層・別の場所でもまとめて動きます
- 階段・転移門に乗ると接続先へ移動
- 穴の上には進めない。同じマスに橋があれば歩ける
- 未訪問区画は闇。進入した区画だけが一気に開示されます（穴があっても部屋・道の区画は割れません）
- **Esc** でタイトルに戻る

「探索リセット」で位置・マスク・扉状態だけを開始時点に戻せます。マップは消えません。

## 画面共有（PlayView）

GitHub Pages の URL を `PlayView/` まで伸ばすと、**ホストが見ている迷宮を、その URL を開いた全員が同じ画面として視聴**できます。

例: `https://makimaki510151.github.io/MitidureGatari/PlayView/`

1. ホストは通常どおりサイトを開き、プレイまたはクリエイトを開始する
2. 「画面を共有」を押す（共有URLがコピーされます）
3. 視聴者はその `PlayView/` を開く。ホストの視点・探索マスク・扉・位置がそのまま映ります（操作はホストのみ）

部屋を分けたいときは `PlayView/#部屋名` のようにハッシュを付けます。ホスト側のページにも同じ `#部屋名` を付けてから共有してください。

接続はブラウザ同士の通信です。ホストが切れると視聴側は待機画面に戻ります。

## JSON

ヘッダーの **JSON** から、現在のマップを編集・ファイル保存・ファイル読込できます。「適用して使う」で反映され、そのままプレイできます。チェックを入れると探索状況（位置・マスク・扉）も含まれます。
